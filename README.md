# SQL-DataBase-Query-Design

A really fun project i made to deepen my SQL skills it didnt take alot of time to do more likely 2 days to make, i used Movies/Boxoffice as an example here, it might get alot of updates soon like triggers and stored procedures.

PostgreSQL database project with movies/boxoffice data featuring:
- Views with CASE statements
- ROLLUP aggregations
- Performance analysis with EXPLAIN ANALYZE
- Data cleaning patterns
- EXPLAIN/ANALYZE
  

## Schema
- Movies table (id, title, release_year, genre, director, length_minutes)
- BoxOffice table (movie_id, rating, domestic_sales, international_sales)

## Key Queries
- Rating categorization with emoji indicators
- Genre-based rollups
- Director analysis
